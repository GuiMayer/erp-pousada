# Respostas sobre o restaurante — referência arquivada

Recebidas em 09/10/2026. O cliente contratou outro sistema para o restaurante; estas regras não integram o escopo ativo nem bloqueiam as sprints da pousada.

| Tema | Resposta confirmada |
| --- | --- |
| Separação financeira | Pousada e restaurante usam caixas separados e contas separadas. |
| Quantidade contratada | A empresa informa a quantidade de refeições por dia. |
| Apuração | Combina-se um valor aproximado; a cobrança considera a medição de quantas pessoas efetivamente vieram comer. |
| Identificação | Registra-se qual funcionário comeu, com assinatura do colaborador no atendimento presencial. |
| Marmitas | Registra-se o fornecimento sem assinatura. |

Não interpretar o valor aproximado como obrigação de cobrar uma quantidade fixa. Uma eventual retomada precisaria confirmar a política de cobrança e o processo de assinatura com o cliente.
